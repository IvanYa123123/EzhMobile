# Тесты EzhMobile

Два независимых набора: HTTP API на Python и смоук интерфейса на jsdom.
Оба запускаются в CI отдельным workflow `Tests` (`.github/workflows/tests.yml`),
сборка APK (`build.yml`) от них не зависит.

## Зачем это

Смоук-тесты — это **регрессионные** тесты: каждый исправленный баг получает
проверку, которая падала бы до исправления. Так баг не возвращается незаметно
(особенно после правок в общем бандле `app.bundle.js`).

Правило простое: **новый баг → новый тест в подходящий файл**. Не обязательно
писать тест на каждую строчку; достаточно одной проверки на сценарий, который
был сломан. Дешёвые проверки (формат ответа, заголовки, наличие элементов)
пишутся сразу; дорогие сценарии (полный прогон UI) — только для того, что уже
ломалась.

## Python: `tests/test_api.py`

Приложение поднимается через Flask `test_client` на временном каталоге данных
(`EZH_DATA_DIR`), сеть СевГУ не дёргается — планировщик и загрузка
преподавателей подменяются заглушками.

Запуск:

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

Что покрыто: версия `/api/health`, единый бандл в `index.html`, `Cache-Control:
no-cache` для `/static/` (иначе WebView показывает старый интерфейс после
обновления APK), CSP, CRUD задач/друзей/предметов/своих пар/лабораторных,
бэкап туда-обратно, заголовок `X-Schedule-Exhausted` и пометка синка только при
полной загрузке, `.ics` (409 до загрузки, 200 после), список преподавателей из
`teachers.json` без сети, фильтр «не-людей» (`Вакансия УПП`, `0 - ОМР`),
`/api/moodle/status` и срабатывание rate-limit.

## Интерфейс: `tests/js/ui.test.mjs`

`tests/stub_server.py` поднимает настоящее приложение с заглушками сети, а
jsdom загружает страницу целиком (включая `app.bundle.js`, bootstrap и chart.js).
Проверяется то, что уже ломалось:

- страница инициализируется без `ReferenceError`, группа восстанавливается из
  `localStorage` (баг «приложение забыло группу», «не открываются настройки»);
- модалка настроек реально открывается;
- после вкладки «День» стрелки в «Расписании» листают неделю, а не день;
- переключатель «Друзья/Преподаватели» виден на телефоне, и у преподавателя
  рисуются карточки пар;
- у друга с подгруппой «0» в заголовке написано «все подгруппы».

Запуск (нужны Node 20+, Python и скачанные vendor-ассеты):

```bash
pip install -r requirements-dev.txt
python scripts/fetch_vendor_assets.py
cd tests/js && npm install && node --test ui.test.mjs
```

## Чего здесь нет

- Полноценных E2E-браузеров (Playwright) и эмулятора Android — оба слишком
  тяжёлые для каждого коммита.
- Тестов плавающей вёрстки: они ломаются от косметики и не ловят логику.
